Relations, Functions and Evaluating Them

What you will learn
  • Tell a function from a general relation
  • Evaluate a function at a given number
  • Avoid sign errors when substituting

Relations and functions

A relation is a set of ordered pairs (input, output). The first number is the input and the second is the output.

A relation is a function when every input is paired with exactly one output. Think of a machine: you put in a number and always get one fixed result.

A relation can be shown as ordered pairs, a table, an arrow diagram, an equation or a graph; the same rule applies to all of them.

  • To test a relation written as pairs: look for an input that repeats with two different outputs. If there is one, it is not a function.
  • A repeated output is fine: two different inputs may give the same output.
  • On a graph: a vertical line stands for one input, so if it meets the curve more than once that input has more than one output, and the graph is not a function.

Evaluating a function

The symbol f(x) is read "f of x" and is the output when the input is x. It does not mean f times x.

To find f(3), replace every x in the rule by 3. If the number is negative, put it in brackets so the sign is not lost.

The input may be an expression, not a number, such as f(a+1): put the whole expression in brackets in place of x. If f(x)=2x+3 then f(a+1)=2(a+1)+3=2a+5.

Laws and rules

Value of a functionf(a)=result of putting a in place of xa is the input; the result is the output.

Worked examples

Which of these relations is a function: {(2,4),(3,4),(5,7)} or {(2,4),(3,5),(2,7)}?
Show the solution
  1. In the first relation the inputs 2, 3 and 5 are different, so each input has one output.
  2. The output 4 appears with two different inputs, which is allowed.
  3. In the second relation the input 2 appears with the outputs 4 and 7, so this input has two outputs.
Answer: The first is a function; the second is not.
If f(x)=x2+3x, find f(−2).
Show the solution
  1. Substitute x=−2 in brackets: f(−2)=(−2)2+3(−2).
  2. (−2)2=4 and 3(−2)=−6.
  3. 4+(−6)=−2.
Answer: f(−2)=−2
If f(x)=2x2−x+1, find f(3)−f(−1).
Show the solution
  1. f(3)=2(9)−3+1=18−3+1=16.
  2. f(−1)=2(1)−(−1)+1=2+1+1=4.
  3. 16−4=12.
Answer: 12
Common mistakes
  • Thinking a relation is not a function because an output repeats. What matters is an input repeating with different outputs.
  • Writing −22=4. In fact (−2)2=4 but −22=−4, so use brackets when substituting a negative number.
  • Reading f(x) as multiplication. It names the output at input x.
  • Writing f(a+1)=f(a)+1. Substituting changes the input inside the rule, so replace x by the whole expression (a+1) in brackets.
Summary
  • A function gives every input exactly one output.
  • A repeated output is allowed; a repeated input with different outputs is not.
  • To evaluate, substitute into the rule and use brackets for negative numbers.

Domain and Range

What you will learn
  • Find the domain and range from pairs
  • Exclude values that make a function undefined
  • Find the range of a simple quadratic

What are domain and range?

The domain is the set of all allowed inputs and the range is the set of all outputs that come out.

For a set of ordered pairs, the domain is the first numbers and the range is the second numbers, each written once.

On a graph, the domain is how far the curve stretches horizontally along the x-axis, and the range is how far it stretches vertically along the y-axis.

Domain restrictions

The domain is all real numbers unless something forbids a value; so the domain of a polynomial such as x2+3 is all real numbers. Two things forbid most often:

  • A denominator can not be zero: set it equal to zero and exclude those solutions.
  • The expression under a square root can not be negative: put the expression under the root ≥0 and solve the inequality.

Finding the range

Ask what smallest or largest value the output can reach. For example x2 is never negative, so its smallest value is 0. Multiplying by −1 reverses the direction, so −x2 is never positive.

Then adding or subtracting a number moves that limit up or down: the range of −x2+4 is every number not more than 4.

Laws and rules

Fraction ruledenominator=0Exclude every number that makes the denominator zero.
Root ruleexpression under the root≥0The square root of a negative number is not defined in the real numbers.

Worked examples

Find the domain and range of {(1,5),(2,7),(3,5)}.
Show the solution
  1. Domain: the first numbers: 1, 2 and 3.
  2. Range: the second numbers: 5, 7 and 5.
  3. Do not repeat a value: the range is 5 and 7 only.
Answer: Domain {1,2,3}, range {5,7}
Find the domain of f(x)=x2−4x+1​​.
Show the solution
  1. Root: the expression under it is not negative, so x+1≥0 and x≥−1.
  2. Denominator: x2−4=0, so x=2 and x=−2.
  3. The number −2 is below −1, so it is already excluded; only 2 remains to exclude.
Answer: x≥−1 and x=2, that is [−1,2)∪(2,∞)
Find the range of f(x)=−x2+4.
Show the solution
  1. x2≥0 for every real number x.
  2. Multiply by −1 and the direction flips: −x2≤0.
  3. Add 4: −x2+4≤4.
  4. The value 4 is reached at x=0.
Answer: Range (−∞,4]
Common mistakes
  • Simplifying the fraction before finding the domain. Exclude the denominator values of the function as it was written: x−2x2−4​ simplifies to x+2, but 2 stays excluded.
  • Mixing domain with range. Domain is the first numbers, range the second, each written once.
  • Thinking the range of −x2+4 is [4,∞). The negative sign makes 4 the largest value, not the smallest.
Summary
  • Domain: all allowed inputs. Range: all outputs.
  • Exclude zeros of the denominator and square roots of negatives.
  • For the range, find the largest or smallest value, and watch a negative sign.

Special Functions: Piecewise, Absolute Value and Greatest Integer

★ Key
What you will learn
  • Evaluate a piecewise function by choosing the right rule
  • Solve absolute value equations
  • Use the greatest integer function and step functions

Piecewise functions

It has several rules, each with a condition on x. To evaluate at a number: see which condition the number satisfies, then use that rule only.

Watch the boundary: if the condition is x≥2 then 2 uses this rule; if it is x<2 then it does not.

Absolute value

The absolute value of a number is its distance from zero, so it is never negative: ∣3∣=3 and ∣−3∣=3. It is a piecewise function: ∣x∣=x when x≥0 and ∣x∣=−x when x<0.

The graph of f(x)=∣x−3∣+1 has two straight arms that meet at a vertex and open upward. The vertex is where the expression inside the absolute value becomes zero: x=3, and there f=0+1=1, so the vertex is (3,1).

It can be written as a piecewise function: f(x)=x−2 when x≥3, and f(x)=4−x when x<3. Its value at x=−2 is ∣−5∣+1=6.

To solve ∣a∣=b with b≥0: either a=b or a=−b, so there are usually two solutions.

Greatest integer and step functions

⌊x⌋ is the greatest integer not more than x. Examples: ⌊3.7⌋=3, ⌊5⌋=5, ⌊−2.5⌋=−3. For negative numbers we move down, not toward zero.

Its graph looks like stairs, so it is called a step function: the value is 2 for every x in 2≤x<3, with a filled dot at the start and an open circle at the end, and then the function jumps to 3.

Step functions appear in situations like "per hour or part of an hour": any part of an hour counts as a full hour, so we round up.

Laws and rules

Absolute value∣x∣=x if x≥0and it equals −x if x<0.
Absolute value equation∣a∣=b⇒a=b or a=−bb is not negative. If b is negative there is no solution.
Greatest integer⌊x⌋≤x<⌊x⌋+1⌊x⌋ is the largest integer that does not exceed x.

Worked examples

If f(x)=2x+1 when x<2 and f(x)=x2−1 when x≥2, find f(2)+f(0).
Show the solution
  1. 2 satisfies x≥2, so use x2−1: f(2)=4−1=3.
  2. 0 satisfies x<2, so use 2x+1: f(0)=1.
  3. The sum is 3+1=4.
Answer: 4
Solve ∣2x−1∣=5.
Show the solution
  1. Case 1: 2x−1=5, so 2x=6 and x=3.
  2. Case 2: 2x−1=−5, so 2x=−4 and x=−2.
  3. Check: ∣2(3)−1∣=5 and ∣2(−2)−1∣=∣−5∣=5.
Answer: x=3 or x=−2
A car park charges 3 riyals for each hour or part of an hour. How much does a driver pay for 2 hours 10 minutes?
Show the solution
  1. 2 hours 10 minutes is more than 2 hours, and the extra part counts as a full hour.
  2. The counted hours are 3.
  3. The cost is 3×3=9 riyals.
Answer: 9 riyals
Common mistakes
  • In a piecewise function: substituting in both rules. Pick only the rule whose condition the number satisfies, and watch ≥ versus < at the boundary.
  • In an absolute value equation: giving one solution to ∣2x−1∣=5 (it has two cases, positive and negative), or finding two for ∣x−1∣=−2 (an absolute value is never negative, so there is no solution).
  • Thinking ⌊−2.5⌋=−2. The greatest integer not above −2.5 is −3.
  • In step situations: rounding a part of an hour down. "Or part of it" means round up.
Summary
  • Piecewise: use the rule whose condition x satisfies.
  • ∣a∣=b gives two cases: a=b or a=−b.
  • ⌊x⌋ is the greatest integer not above x; for a negative non-integer the result is further from zero.
  • "Or part of it" means the part counts as a whole.

Even and Odd Functions and Graph Transformations

What you will learn
  • Decide whether a function is even, odd or neither
  • Use the odd property to find a value
  • Describe a shift from the rule

Even and odd functions

Replace x with −x in the rule. If the function does not change, that is f(−x)=f(x), it is even and its graph is symmetric about the y-axis, like x2. If it becomes −f(x), the opposite in sign, it is odd and its graph is symmetric about the origin, like x3.

If neither happens, the function is neither even nor odd.

A quick rule for polynomials: if every power of x is even (a constant counts as an even power) the function is even; if every power is odd it is odd; if both kinds appear it is neither even nor odd.

Graph transformations

We start from the graph of f(x) and change the rule slightly to get a shift or a reflection.

Adding outside the bracket moves the graph vertically, as you expect. Adding inside the bracket moves it horizontally, in the opposite direction to what you expect.

  • f(x)+k: shift k units up. f(x)−k: shift k units down.
  • f(x+k): shift k units left. f(x−k): shift k units right.
  • −f(x): reflect in the x-axis. f(−x): reflect in the y-axis.
  • a⋅f(x): if a>1 the graph is stretched vertically, moving away from the x-axis; if 0<a<1 it is squashed toward it.

Laws and rules

Even functionf(−x)=f(x)Symmetric about the y-axis.
Odd functionf(−x)=−f(x)Symmetric about the origin.

Worked examples

If f is an odd function and f(2)=5, find f(−2).
Show the solution
  1. An odd function satisfies f(−x)=−f(x).
  2. At x=2: f(−2)=−f(2).
  3. f(−2)=−5.
Answer: f(−2)=−5
Classify f(x)=x4−3x2 and g(x)=x2+x.
Show the solution
  1. f(−x)=(−x)4−3(−x)2=x4−3x2=f(x), so f is even.
  2. g(−x)=x2−x.
  3. This is not g(x)=x2+x, and not −g(x)=−x2−x.
Answer: f is even; g is neither even nor odd.
How does the graph of f(x)=x2 move to become the graph of f(x−2)+3? Where is the new vertex?
Show the solution
  1. x−2 inside the bracket: shift 2 units right.
  2. +3 outside the bracket: shift 3 units up.
  3. The vertex of x2 is (0,0), so it moves to (2,3).
Answer: 2 right and 3 up; the new vertex is (2,3).
Common mistakes
  • Thinking f(x+4) moves the graph to the right. The sign inside the bracket works backwards: +4 means left.
  • Thinking a function is even because it contains x2. Every term must have an even power; x2+x has an odd term, so it is neither even nor odd.
  • For an odd function writing f(−2)=5. The sign flips, so it is −5.
  • Mixing up −f(x) and f(−x). The first changes the sign of the output (a reflection in the x-axis); the second changes the sign of the input (a reflection in the y-axis).
Summary
  • Even: f(−x)=f(x). Odd: f(−x)=−f(x).
  • If neither holds, it is neither even nor odd.
  • f(x+k) shifts left; f(x−k) shifts right.
  • Adding outside the bracket shifts vertically in the natural direction.

Composition of Functions and the Inverse Function

★ Key
What you will learn
  • Compute the composition of two functions in the correct order
  • Find the rule of the inverse function
  • Check an inverse by substitution

Composition of functions

Composing two functions means the output of the first becomes the input of the second. We write (f∘g)(x)=f(g(x)), read "f after g".

Always start with the inner function (the one inside the bracket), then put its result into the outer function. Order matters: f(g(x)) is usually different from g(f(x)).

The inverse function

The inverse f−1 takes an output back to its input: if f(2)=0 then f−1(0)=2. It undoes what f does.

To find the rule: write y=f(x), swap x and y, then solve for y. The graph of the inverse is the reflection of the graph of f in the line y=x.

A function has an inverse function only if it is one-to-one, that is, no output comes from two different inputs (any horizontal line meets the graph at most once). So x2 on all numbers has no inverse, because 2 and −2 give the same output 4.

Domain and range swap places: the domain of f−1 is the range of f, and its range is the domain of f.

A value of the inverse without its rule

To find f−1(7), look for the input that gives the output 7. If f(x)=2x+1 then 2x+1=7, so x=3, that is f−1(7)=3.

Laws and rules

Composition(f∘g)(x)=f(g(x))Compute g first, then f.
Inversef−1(f(x))=xThe inverse returns the original input.

Worked examples

If f(x)=x+2 and g(x)=x2, find (f∘g)(3) and (g∘f)(3).
Show the solution
  1. (f∘g)(3)=f(g(3)) and g(3)=9.
  2. f(9)=9+2=11.
  3. (g∘f)(3)=g(f(3))=g(5)=25.
Answer: (f∘g)(3)=11 and (g∘f)(3)=25
If f(x)=2x−1 and g(x)=x+3, find (f∘g)(x).
Show the solution
  1. (f∘g)(x)=f(g(x))=f(x+3).
  2. Put x+3 into f: 2(x+3)−1.
  3. =2x+6−1=2x+5.
  4. Check at x=1: g(1)=4 and f(4)=7, and 2(1)+5=7.
Answer: 2x+5
Find the inverse of f(x)=3x−6.
Show the solution
  1. Write y=3x−6.
  2. Swap x and y: x=3y−6.
  3. Solve for y: 3y=x+6, so y=3x+6​.
  4. Check: f(2)=0 and f−1(0)=36​=2.
Answer: f−1(x)=3x+6​
Common mistakes
  • Reversing the order of composition: (f∘g)(x) means apply g first, then f.
  • Thinking f−1(x) means f(x)1​. The exponent −1 here marks the inverse function, not the reciprocal.
  • When finding the inverse: forgetting to swap x and y, or moving a term wrongly. Always check with one number.
Summary
  • (f∘g)(x)=f(g(x)): start from the inner function.
  • Order matters: f∘g is usually not equal to g∘f.
  • Inverse: write y, swap x and y, solve for y.
  • f−1 undoes f, and its graph is the reflection of f in y=x.

Slope, Rate of Change and Linear Models

★ Key
What you will learn
  • Find the slope of a line from two points
  • Find the average rate of change of a function over an interval
  • Build a linear model from a situation or a table

Slope

Slope measures steepness: how much y changes when x increases by 1. It equals the vertical change divided by the horizontal change between any two points on the line.

Take the differences in the same order on top and bottom. If you start with one point on top, start with it at the bottom too.

The sign of the slope gives the direction: a positive slope means y grows with x, a negative slope means it falls, and a horizontal line has slope zero. A vertical line has no defined slope because the horizontal change is zero.

Average rate of change

For any function, the average rate of change over the interval [a,b] is the slope of the line joining the points (a,f(a)) and (b,f(b)) on its graph. It tells us how much the function changes on average for each unit of x.

If the function is linear, its average rate of change is the same on every interval and equals its slope.

Linear models and tables

Many situations have a fixed amount and a steady change, written y=mx+c: m is the change per unit (the slope) and c is the value at x=0.

Example: a taxi charges 5 riyals fixed plus 2 riyals per kilometre: y=2x+5, and for 10 km: 2×10+5=25 riyals.

In a table: if y rises by a constant amount each time x rises by 1, the pattern is linear, and that constant is the slope. To find c, substitute a known point: c=y−mx. If the slope is negative, the decrease is steady.

Worked examples

A line passes through (1,3) and (3,11). Find its slope.
Show the solution
  1. Vertical change: 11−3=8.
  2. Horizontal change: 3−1=2.
  3. Slope =28​=4.
Answer: 4
Find the average rate of change of f(x)=x2−2x on [1,4].
Show the solution
  1. f(4)=16−8=8.
  2. f(1)=1−2=−1.
  3. Rate =4−18−(−1)​=39​=3.
Answer: 3
The values of y for x=1,2,3 are 7,10,13. Find y at x=10 if the pattern continues.
Show the solution
  1. Differences: 10−7=3 and 13−10=3, so the slope is 3.
  2. The model is y=3x+c. At x=1: 7=3+c, so c=4.
  3. y=3x+4, and at x=10: 30+4=34.
  4. Check at x=3: 9+4=13.
Answer: 34
A tank held 120 litres of water, and after 4 minutes it held 80 litres. If the loss continues at a constant rate, write a linear model for the amount of water y (in litres) after x minutes, then find when the tank is empty.
Show the solution
  1. Slope = change in amount ÷ change in time: 4−080−120​=−10 litres per minute.
  2. The starting value at x=0 is c=120, so the model is y=−10x+120.
  3. The tank is empty when y=0: −10x+120=0, so x=12.
  4. Check at x=4: −40+120=80.
Answer: y=−10x+120, and the tank is empty after 12 minutes.
Common mistakes
  • Reversing the order in one of the differences: 1−311−3​=−4 is wrong. Start from the same point on top and bottom.
  • In a table: multiplying the slope by x only and forgetting the constant, which gives 3×10=30, wrong here.
  • For average rate of change: not finding the two values of f first, or adding the values instead of subtracting.
Summary
  • Slope = vertical change ÷ horizontal change.
  • Average rate of change on [a,b] = b−af(b)−f(a)​.
  • Linear model y=mx+c: m per unit, c the starting value.
  • In a table: the constant difference is the slope, then fix the constant with one point.
