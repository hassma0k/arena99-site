Laws of Exponents and Exponential Functions

★ Key
What you will learn
  • Apply the laws of exponents to simplify expressions
  • Recognise an exponential function and tell growth from decay
  • Read the graph: its fixed point and its asymptote

Reminder: laws of exponents

The exponent tells how many times the base is multiplied by itself: 23=2×2×2=8.

Multiplying powers with the same base adds the exponents, and dividing subtracts them. A negative exponent means the reciprocal: 2−3=81​.

A fractional exponent means a root: a21​=a​, so 921​=3. In 832​ take the cube root of 8, which is 2, then square it to get 4.

The exponential function

An exponential function has the form f(x)=ax where the base a is positive and not equal to 1, and the variable x sits in the exponent. We exclude base 1 because 1x is always 1, so it is not a changing function, and we exclude negative bases because something like (−4)21​ is undefined.

Do not confuse it with x3: there the variable is in the base and the exponent is fixed, so it is a power function, not an exponential one.

Growth or decay?

If a>1 the function increases and is called exponential growth, because multiplying by a number larger than 1 again and again makes the result bigger.

If 0<a<1 the function decreases and is called exponential decay, because multiplying by a number smaller than 1 again and again makes the result smaller. For example (31​)x gives 31​, then 91​, then 271​.

Shape of the graph

  • The graph always passes through (0,1) because a0=1.
  • The values are always positive, so the graph stays above the x-axis and never touches it: the x-axis is a horizontal asymptote.
  • The domain is all real numbers and the range is y>0.

Laws and rules

Product of powersam×an=am+na is positive; m and n are exponents.
Quotient of powersanam​=am−nThe base a is not zero.
Power of a power(am)n=am×nMultiply the exponents.
Zero and negative exponentsa0=1 and a−n=an1​a is not zero.
Power of a product(a×b)n=an×bnThe exponent applies to each factor.
Fractional exponenta21​=a​The exponent n1​ means the nth root, and nm​ means the nth root raised to the power m; the base a is positive.

Worked examples

Simplify 23×24÷25.
Show the solution
  1. The base is the same, so add the exponents in the product: 23×24=27.
  2. Then subtract in the division: 27÷25=22.
  3. 22=4.
Answer: 4
If f(x)=3×2x, find f(0), f(2) and f(−1).
Show the solution
  1. f(0)=3×20=3×1=3.
  2. f(2)=3×22=3×4=12.
  3. f(−1)=3×2−1=3×21​=23​.
Answer: 3, 12 and 23​
A 96 g sample of a substance halves every 4 days. How many grams remain after 12 days?
Show the solution
  1. Number of halvings: 12÷4=3.
  2. Mass left =96×(21​)3.
  3. (21​)3=81​.
  4. 96×81​=12.
Answer: 12 g remain
Common mistakes
  • Adding exponents when adding powers: 23+24 is not 27. Exponents add only in a product. Correct: 8+16=24.
  • In (23)2 we multiply the exponents, so the result is 26, not 25.
  • Thinking a0=0. Any non-zero number to the power 0 equals 1.
  • Judging growth or decay from the exponent. Look at the base: above 1 is growth, between 0 and 1 is decay. So 2−x is decay, because it equals (21​)x.
Summary
  • Multiplying adds exponents, dividing subtracts them, a power of a power multiplies them.
  • In ax the variable is in the exponent and the base is positive and not 1.
  • Base above 1 means growth; base between 0 and 1 means decay.
  • The graph passes through (0,1) and never crosses the x-axis.

Exponential Equations and Inequalities

What you will learn
  • Solve an exponential equation by matching bases
  • Solve an exponential inequality and watch the direction of the sign
  • Factor out a common term when several exponential terms appear
  • Solve an exponential equation of quadratic form by substitution

The idea: match the bases

An exponential function takes each value only once, so if two powers with the same base are equal, their exponents are equal: if am=an then m=n.

So we write both sides with one base. For example in 9x=27 write 9=32 and 27=33, giving 32x=33, so 2x=3 and x=23​.

When the bases cannot be matched, as in 2x=7, we take the logarithm of both sides, which we learn in the later lessons.

When several exponential terms meet

If the same base appears with different exponents in two terms, write the larger one in terms of the smaller one and factor. For example 2x+1=2x×2.

Then you reach the form number×2x=number, so divide and match bases.

An equation of quadratic form

Sometimes 4x and 2x appear together. Write 4x=(2x)2 and let y=2x to get a quadratic equation. For example 4x−6×2x+8=0 becomes y2−6y+8=0, that is (y−2)(y−4)=0, so y=2 or y=4, giving x=1 or x=2.

If a negative value comes out for y, reject it, because 2x is never negative.

Exponential inequalities

Match the bases again, then look at the base. If it is larger than 1 the function increases, so the sign stays the same when you compare exponents.

If the base is between 0 and 1 the function decreases, so the sign flips. The sign also flips whenever you multiply both sides by a negative number.

When is there no solution?

An exponential power is always positive, so 2x=−4 has no solution, and 2x>−4 is true for every x.

Laws and rules

Equal powersam=an→m=nThe base a is positive and not 1.
Inequality with base above 1am<an→m<nWhen a>1 the direction stays.
Inequality with base between 0 and 1am<an→m>nWhen 0<a<1 the direction flips.

Worked examples

Solve 2x+1=32.
Show the solution
  1. Write 32=25.
  2. So 2x+1=25.
  3. The bases are equal, so equate the exponents: x+1=5.
  4. x=4. Check: 25=32.
Answer: x=4
Solve 2x+1+2x=24.
Show the solution
  1. Write 2x+1=2×2x.
  2. So 2×2x+2x=24.
  3. Factor: 3×2x=24.
  4. Divide by 3: 2x=8=23.
  5. So x=3. Check: 24+23=16+8=24.
Answer: x=3
Solve (21​)x>4.
Show the solution
  1. Write both sides with base 2: (21​)x=2−x and 4=22.
  2. The inequality becomes 2−x>22.
  3. The base 2 is larger than 1, so the sign stays: −x>2.
  4. Multiply by −1 and the sign flips: x<−2.
  5. Check with x=−3: (21​)−3=8>4, true.
Answer: x<−2
Common mistakes
  • Equating exponents before matching bases: in 9x=27 do not write x=3; first convert to base 3.
  • Writing 2x+1=2x+2. The correct form is 2x+1=2x×2.
  • Forgetting to flip the sign for a base between 0 and 1, or when multiplying by a negative number.
  • Looking for a solution to something like 3x=−9: a positive power never equals a negative number.
Summary
  • Match the bases, then equate the exponents.
  • With terms of different exponents, factor out a common term.
  • Base above 1 keeps the sign; base between 0 and 1 flips it.
  • An exponential power is never negative and never zero.

Logarithms and Logarithmic Functions

★ Key
What you will learn
  • Convert between exponential and logarithmic form
  • Evaluate simple logarithms without a calculator
  • Find the domain of a logarithmic function and read its graph

What is a logarithm?

A logarithm is an exponent. When we ask for log2​8 we are asking: to what power must 2 be raised to give 8? The answer is 3.

We write: loga​x=y means exactly ay=x. The two forms say the same thing, and this is the key to every problem.

How to evaluate

Convert to exponential form, then match bases. For example log10​0.01: write 10y=0.01=10−2, so the result is −2.

Two values never change: loga​1=0 because a0=1, and loga​a=1 because a1=a.

Restrictions

The base needs a>0 and a=1, and the number inside needs x>0. A positive base raised to any power never gives zero or a negative number, so log2​(−4) and log2​0 do not exist.

The logarithmic function

The function f(x)=loga​x is the inverse of the exponential function ax, so its graph is the reflection of the exponential graph in the line y=x.

Its domain is x>0, its range is all real numbers, it passes through (1,0), and the y-axis is a vertical asymptote.

  • If a>1 the function is increasing; if 0<a<1 it is decreasing.
  • The domain of each of the exponential and logarithmic functions is the range of the other.

Laws and rules

Definition of a logarithmloga​x=y→ay=xa>0, a=1, and x>0.
Two special valuesloga​1=0 and loga​a=1Because a0=1 and a1=a.
Logarithm and power cancelloga​(ax)=xThe logarithm undoes the exponent.

Worked examples

Evaluate log2​32 and log3​91​.
Show the solution
  1. Let log2​32=y, so 2y=32=25 and y=5.
  2. Let log3​91​=y, so 3y=91​=3−2.
  3. So y=−2.
Answer: 5 and −2
Find x in each case: (a) log3​x=−2, (b) logx​81=4.
Show the solution
  1. (a) Convert: x=3−2=321​=91​.
  2. (b) Convert: x4=81=34.
  3. The base must be positive, so take the positive fourth root: x=3.
Answer: (a) 91​, (b) 3
Find the domain of f(x)=log2​(x−3), then compute f(11).
Show the solution
  1. The number inside must be positive: x−3>0.
  2. So the domain is x>3.
  3. f(11)=log2​(11−3)=log2​8.
  4. 23=8, so f(11)=3.
Answer: Domain x>3 and f(11)=3
Common mistakes
  • Reading log3​9 as 3×9 or 93. Correct: ask 3y=9, so y=2.
  • Saying loga​1=1. In fact loga​1=0; it is loga​a that equals 1.
  • Taking the logarithm of a negative number or zero: log2​(−4) and log2​0 are undefined.
  • Forgetting the domain condition: whatever is inside the logarithm must be greater than zero.
Summary
  • loga​x=y means ay=x: a logarithm is an exponent.
  • loga​1=0 and loga​a=1 always.
  • The base is positive and not 1; the number inside is positive.
  • The graph of loga​x passes through (1,0) and its domain is x>0.

Properties of Logarithms

★ Key
What you will learn
  • Add and subtract logarithms with the same base
  • Move an exponent to the front of a logarithm
  • Change base and simplify expressions such as aloga​x

Where do the properties come from?

A logarithm is an exponent, and the laws of exponents say that multiplying powers adds their exponents. So multiplying two numbers turns into adding their logarithms.

In this way logarithms turn multiplication into addition, division into subtraction, and powers into multiplication. From the quotient rule we also get loga​x1​=−loga​x.

The same base is required

The properties only work when the logarithms have the same base. There is no rule for simplifying loga​(x+y), so never split it into a sum.

Change of base

If the base is inconvenient, switch to a common base b: loga​x=logb​alogb​x​. For example log4​8=log2​4log2​8​=23​.

From the definition we also get aloga​x=x: raising the base to the logarithm of a number with that same base returns the number.

Two useful cases: loga​b×logb​a=1, and changing to a shared base that both numbers are powers of: log8​4=log2​8log2​4​=32​, because 4 and 8 are powers of 2.

Laws and rules

Product ruleloga​(x×y)=loga​x+loga​yx and y are positive.
Quotient ruleloga​yx​=loga​x−loga​yx and y are positive.
Power ruleloga​(xn)=n×loga​xn is any real number.
Change of baseloga​x=logb​alogb​x​b is a new base, positive and not 1.
Base raised to a logarithmaloga​x=xx>0.
Reciprocal logarithmsloga​b×logb​a=1a and b are positive and neither equals 1.

Worked examples

Evaluate log2​4+log2​8.
Show the solution
  1. The base is the same, so adding means multiplying the insides: log2​(4×8)=log2​32.
  2. 25=32, so the result is 5.
  3. Check: log2​4=2 and log2​8=3, and they add to 5.
Answer: 5
Evaluate 2log2​5+1.
Show the solution
  1. Split the exponent: 2log2​5+1=2log2​5×21.
  2. 2log2​5=5 by the rule.
  3. The result is 5×2=10.
Answer: 10
Simplify 2×log3​6−log3​4.
Show the solution
  1. Move the coefficient into the power: 2×log3​6=log3​(62)=log3​36.
  2. Subtract with the same base, so divide: log3​36−log3​4=log3​436​=log3​9.
  3. 32=9, so the result is 2.
Answer: 2
Common mistakes
  • Writing log2​4+log2​8=log2​12. Adding means multiplying the insides, not adding them.
  • Saying log2​4log2​8​ equals log2​2. That is a quotient of two logarithms and equals 23​, while log2​48​=1.
  • Splitting log2​(x+3) into log2​x+log2​3. There is no rule for a sum inside a logarithm.
  • Moving a coefficient wrongly: 2×log2​3=log2​9, not log2​6, because the coefficient becomes an exponent.
Summary
  • Products become sums: loga​(x×y)=loga​x+loga​y.
  • Quotients become differences, and an exponent becomes a coefficient in front.
  • Every rule needs one common base, and there is no rule for loga​(x+y).
  • aloga​x=x and loga​x=logb​alogb​x​.

Common and Natural Logarithms

What you will learn
  • Know that log means base 10 and ln means base e
  • Use a given value such as log2≈0.3 to find other logarithms
  • Simplify expressions that combine ln and the function ex

The common logarithm

When we write logx with no base we mean base 10, that is log10​x. So log100=2, log1000=3 and log0.01=−2.

The number of zeros in a power of ten is its logarithm: 1000 has three zeros, so its logarithm is 3.

Using a given value

Often you are given log2≈0.3 and asked for the logarithm of another number. Break the number into 2s and powers of ten, then use the sum and difference rules.

For example 40=4×10 and 4=22, and 5=210​. No log table is needed.

To find a logarithm with another base, change the base to 10: log2​5=log2log5​≈0.30.7​≈2.3.

The natural logarithm

The number e≈2.718 is an important constant that appears in growth and decay. The logarithm with base e is called natural and is written lnx; it means lnx=y when ey=x.

All the properties of logarithms apply to it, and it has special values: lne=1 and ln1=0. It is the inverse of the function ex.

Laws and rules

Common logarithmlogx=log10​xlog10=1 and log1=0.
Natural logarithmlnx=y→ey=xe is a constant, about 2.718.
Mutual cancellationln(ex)=x and elnx=xThe first holds for all x, the second for x>0.

Worked examples

Evaluate log1000+log0.1.
Show the solution
  1. log1000=3 because 103=1000.
  2. log0.1=−1 because 10−1=0.1.
  3. The sum is 3+(−1)=2.
Answer: 2
If log2≈0.3, find approximately log40 and log5.
Show the solution
  1. 40=4×10=22×10.
  2. log40=2×log2+log10=2×0.3+1=1.6.
  3. 5=210​, so log5=log10−log2=1−0.3=0.7.
Answer: log40≈1.6 and log5≈0.7
Simplify ln(e5)−lne1​.
Show the solution
  1. ln(e5)=5.
  2. e1​=e−1, so lne1​=−1.
  3. The result: 5−(−1)=6.
Answer: 6
Common mistakes
  • Thinking log with no base means base 2 or base e. In fact log is base 10 and ln is the natural one.
  • Writing log(2+3)=log2+log3. The sum belongs to a product: log2+log3=log6.
  • Saying lne=e. In fact lne=1.
  • Forgetting log10=1 when breaking numbers apart: log40=2×log2+1, not just 2×log2.
Summary
  • log with no base means base 10, and the logarithm of 10n is n.
  • Break the number into powers of 2 and 10 and use the given value.
  • ln is the logarithm with base e; lne=1 and ln1=0.
  • ln(ex)=x and elnx=x.

Logarithmic Equations and Inequalities

What you will learn
  • Solve a log equation by converting to exponential form or by combining logs
  • Check the domain and reject extraneous solutions
  • Solve a log inequality with the domain condition
  • Bring the variable out of an exponent by taking a logarithm

Two ways to solve

First: combine the terms into a single logarithm on one side, then convert to exponential form. For example log2​(x+1)=3 becomes x+1=23.

Second: one logarithm on each side with the same base, so equate the insides: loga​m=loga​n means m=n.

The step you must not forget: the domain

Before solving, write that everything inside any logarithm is positive. After solving, test each result: a solution that makes the inside of a logarithm negative or zero is rejected, because it is extraneous.

Extraneous solutions often appear when you get a quadratic with two roots, one of them invalid.

An exponential equation whose bases will not match

When the bases cannot be matched, take the logarithm of both sides and bring the exponent down as a coefficient: from 3x=5 we get x×log3=log5, so x=log3log5​.

So the logarithm is the tool that brings the variable out of the exponent.

Logarithmic inequalities

Write both sides as logarithms with the same base, then compare the insides. If the base is larger than 1 the sign stays; if it is between 0 and 1 the sign flips.

Do not forget that everything inside a logarithm is positive, so the answer is the overlap of the comparison result with the domain condition.

Laws and rules

Equation with one logarithmloga​m=n→m=anm must be positive.
Equal logarithmsloga​m=loga​n→m=nm>0 and n>0.
Inequality with base above 1loga​m<loga​n→0<m<nWhen a>1; if 0<a<1 the comparison flips.

Worked examples

Solve log2​(x+1)=3.
Show the solution
  1. Convert to exponential form: x+1=23=8.
  2. So x=7.
  3. Check the domain: 7+1=8>0, accepted.
Answer: x=7
Solve log3​x+log3​(x−2)=1.
Show the solution
  1. Domain: x>0 and x−2>0, that is x>2.
  2. Combine: log3​[x(x−2)]=1.
  3. Convert: x2−2x=31=3, that is x2−2x−3=0.
  4. Factor: (x−3)(x+1)=0, so x=3 or x=−1.
  5. x=−1 fails x>2 and is rejected. Check x=3: log3​3+log3​1=1+0=1.
Answer: x=3
Solve log2​(x−1)<3.
Show the solution
  1. Domain: x−1>0, that is x>1.
  2. Write 3=log2​8, so log2​(x−1)<log2​8.
  3. The base 2 is larger than 1, so the sign stays: x−1<8, that is x<9.
  4. Combine with the domain: 1<x<9.
  5. Check: at x=9 we get log2​8=3, which is not less than 3, so 9 is excluded.
Answer: 1<x<9
Common mistakes
  • Skipping the domain check and accepting a solution that makes the inside of a log negative, like x=−1 in the second example.
  • Converting wrongly: log2​(x+1)=3 means x+1=23, not x+1=2×3.
  • Writing log3​x+log3​(x−2)=log3​(2x−2). Adding means multiplying: log3​[x(x−2)].
  • Solving an inequality without the condition x>1, so numbers outside the domain sneak into the answer.
Summary
  • Write the domain first: everything inside a log is positive.
  • Combine into one log and convert to exponential form, or equate the insides of matching logs.
  • Reject any solution that fails the domain.
  • For inequalities: base above 1 keeps the sign, and the answer overlaps with the domain.

Compound Growth and Exponential Decay

What you will learn
  • Write a growth or decay model in exponential form
  • Compute the value after a number of periods
  • Find the time needed by matching bases

Why an exponent?

When a quantity grows by a fixed percentage each period, we multiply by the same factor every time. After n periods we have multiplied n times, which gives a power.

This is different from linear growth, which adds a fixed amount each period.

Compound growth and decay

An initial amount y0​ that changes by a rate r each period becomes, after n periods: y=y0​×(1+r)n for growth and y=y0​×(1−r)n for decay.

Write the rate r as a decimal: 10% means r=0.1. Note that compound interest is calculated on the new amount each time, so it is larger than simple interest.

Doubling and halving

If the quantity doubles each period then y=y0​×2n, and if it halves then y=y0​×(21​)n.

Careful: n is the number of periods, not the time itself. Number of periods =length of periodtime​.

Several additions a year and continuous growth

If interest is added k times a year, the rate per period is kr​ and the number of periods is k×t, where t is the number of years: y=y0​×(1+kr​)k×t.

For example 1000 riyals at 12% a year added every 6 months (k=2): the rate per period is 0.06, and after one year y=1000×1.062=1123.6 riyals, which is more than the 1120 from adding it once.

When growth is continuous, moment by moment, we use the number e: y=y0​×er×t, and to find t we take ln of both sides.

Finding the time

Put the target value into the equation and match bases if possible. If not, take the logarithm of both sides and bring the exponent down: from 1.1n=2 we get n=log1.1log2​.

Laws and rules

Compound growthy=y0​×(1+r)ny0​ is the starting value, r the growth rate per period (as a decimal), n the number of periods.
Decayy=y0​×(1−r)nr is the decrease rate per period, n the number of periods.
Doublingy=y0​×2nn is the number of doublings =doubling periodtime​.
Halvingy=y0​×(21​)nn is the number of halvings =half-lifetime​.
Several additions a yeary=y0​×(1+kr​)k×tr is the yearly rate, k the number of additions per year, t the number of years.
Continuous growthy=y0​×er×tr is the yearly rate, t the number of years, and e≈2.718.

Worked examples

1000 riyals are invested at 10% compound interest per year. How much is there after two years?
Show the solution
  1. r=0.1 and n=2, so y=1000×(1.1)2.
  2. 1.12=1.21.
  3. y=1000×1.21=1210.
  4. Check: year one gives 1100, then 10% of 1100 is 110, giving 1210.
Answer: 1210 riyals
A machine is worth 4800 riyals and its value halves every 2 years. After how many years is it worth 300 riyals?
Show the solution
  1. Write 300=4800×(21​)n.
  2. (21​)n=4800300​=161​.
  3. 161​=(21​)4, so n=4 periods.
  4. Time =4×2=8 years.
  5. Check: 4800, then 2400, 1200, 600, 300.
Answer: 8 years
A colony of 50 bacteria doubles every 2 hours. How many are there after 6 hours? When does it reach 1600?
Show the solution
  1. After 6 hours: n=6÷2=3 periods.
  2. y=50×23=50×8=400.
  3. To reach 1600: 50×2n=1600, so 2n=32=25.
  4. So n=5 periods and the time is 5×2=10 hours.
Answer: 400 bacteria after 6 hours, and 10 hours to reach 1600
Common mistakes
  • Using the time in place of the number of periods: halving every 2 years over 8 years means n=4, not 8.
  • Writing r=10 instead of 0.1 for a 10% rate, so the factor becomes 11 instead of 1.1.
  • Treating compound interest as linear: 1000 riyals after two years at 10% is 1210, not 1200.
  • In decay multiply by (1−r), not (1+r); the factor is below 1.
Summary
  • Growth or decay by a fixed percentage is exponential: y=y0​×(1±r)n.
  • r is a decimal, and n is the number of periods, not the time.
  • Doubling multiplies by 2 and halving multiplies by 21​ each period.
  • To find the time, match the bases or use a logarithm.
